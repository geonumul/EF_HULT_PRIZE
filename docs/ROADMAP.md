# 개발 단계

한 단계가 끝나면 커밋하고 이 표의 상태를 바꾼다.

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 저장소 뼈대, 배포 구조 문서, 디자인 토큰 CSS | 완료 |
| 2 | Next.js 앱 생성, 공통 레이아웃(Header, Footer), 안내 페이지 | 진행 중 |
| 3 | S01·S02 공실 지도 화면. Button·Chip 컴포넌트, 카카오맵, 가짜 데이터 | 대기 |
| 4 | Supabase 스키마 적용, `backend/`의 공실 API, 지도 화면 연결 | 대기 |
| 5 | S03 공간 스튜디오, S04 텍스트 렌더링 화면. 렌더링 방식 선택(이미지 먼저 / 상품 먼저) 포함 | 대기 |
| 6 | Firebase 렌더링 작업(`text`, `products` 두 방식), 상품 매칭, 견적 계산 | 대기 |
| 7 | S05 견적 확정, S06 결제 완료. 토스페이먼츠 연결 | 대기 |
| 8 | S07 집기 마켓(렌더링 보드 담기 포함), S08 창업 가이드, S09 로그인, S10 파트너 콘솔, S11 입점 문의 | 대기 |
| 9 | 철거 견적 추정, 철거 업체 매칭(요청, 견적 비교, 선택, 후기). [FEATURES.md](FEATURES.md) 참고 | 대기 |
